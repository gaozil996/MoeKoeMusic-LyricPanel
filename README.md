# 歌词悬浮面板

把 MoeKoe Music 的原生播放栏移进全屏歌词页。它是原来的同一个 DOM，不复制、不重排按钮：播放、进度、桌面歌词、频谱、下载、收藏、倍速、队列、音量以及其他插件注入的控制都保持原样。

## 行为

- 播放栏铺满歌词页底部，保持宿主本身的尺寸、间距和样式。
- 进入歌词页先半透明；鼠标悬停时完全清晰；离开播放栏后按设置淡到全透明。
- 隐藏歌词页右上角关闭按钮，改由播放栏歌名/封面关闭歌词页；只有播放栏确实挂上后才隐藏，插件失效时宿主关闭按钮会回来。
- 隐藏歌词页重复的进度条，只保留搬入的原生播放栏进度条。
- 歌词页里播放列表按钮可用，队列弹层显示在歌词层之上，不会被整页盖住。
- 歌词页队列改为紧凑单行，歌曲时长显示在歌名后；虚拟列表步长同步由 50px 降到 36px，同屏可见更多歌曲，点歌、删除和滚动仍由宿主处理。
- 淡出程度可在歌词设置面板里调整。

## 安装

将整个仓库目录放到 `%APPDATA%\moekoemusic\extensions\`，重启 MoeKoe Music。

## 兼容性

插件依赖宿主 `.player-container` 播放栏及 `.lyrics-screen` 全屏歌词页；播放栏不是 `#player-container`。内容脚本失效时不隐藏宿主关闭按钮，也不会移除宿主菜单。
